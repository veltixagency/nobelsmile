# Noble Smile Studio - Modern Dental Clinic Web Application

A full-featured, responsive dental clinic web application built with **React**, **TypeScript**, **Tailwind CSS v4**, and **Vite**.

---

## 🚀 Quick Start Guide (Local Setup)

### 1. Prerequisites
- **Node.js** (v18.0.0 or higher recommended, e.g. Node 20 LTS)
- **npm** (comes with Node.js) or **pnpm** / **yarn** / **bun**

---

### 2. Installation
Extract the zip file and navigate into the project directory in your terminal:

```bash
cd noble-smile-studio
npm install
```

---

### 3. Running in Development Mode
Start the Vite local development server with Hot Module Reloading (HMR):

```bash
npm run dev
```

Open your browser and navigate to:
**http://localhost:3000** (or the port displayed in your terminal).

---

### 4. Building for Production
Create an optimized production bundle:

```bash
npm run build
```

This compiles your TypeScript and assets into the `dist/` directory.

---

### 5. Previewing the Production Build
To test the production build locally before deploying:

```bash
npm run preview
```

---

## 📋 Available npm Scripts

| Command | Action |
| :--- | :--- |
| `npm run dev` | Runs the Vite dev server with live reload |
| `npm run build` | Builds optimized production static bundle in `dist/` |
| `npm run preview` | Runs a local static server to test the production build |
| `npm run lint` | Runs TypeScript type checking (`tsc --noEmit`) |
